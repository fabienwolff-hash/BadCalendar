# BC-14.4 — Finalisation et stabilisation

# Objectif

Cette sous-issue finalise la version v0.14.

Elle consiste à vérifier que les améliorations de l'expérience utilisateur sont correctement intégrées, cohérentes et conformes aux spécifications définies pour cette version.

Aucune nouvelle fonctionnalité n'est développée dans cette sous-issue.

---

# Contexte

Les sous-issues précédentes ont permis :

- la persistance des préférences utilisateur ;
- l'amélioration des cartes de compétition ;
- la gestion des nouveaux tournois.

Cette dernière étape vise à garantir une expérience utilisateur homogène avant la clôture de la version.

---

# Vérifications fonctionnelles

Les scénarios suivants doivent être validés.

## Persistance des préférences

Vérifier que :

- les filtres persistés sont correctement restaurés au démarrage ;
- les filtres non persistés sont réinitialisés ;
- le comportement est identique après fermeture puis réouverture de l'application.

---

## Réinitialisation des filtres

Vérifier que le bouton **Réinitialiser les filtres** :

- réinitialise les filtres actifs ;
- supprime les préférences enregistrées dans le Local Storage.

---

## Cartes de compétition

Vérifier que :

- les informations principales sont immédiatement visibles ;
- les cartes restent compactes lorsqu'elles sont repliées ;
- les informations détaillées apparaissent uniquement après dépliage.

---

## État des inscriptions

Vérifier que l'indicateur visuel correspond toujours à l'état réel des inscriptions :

- ouvertes ;
- ouverture prochaine ;
- closes.

---

## Nouveaux tournois

Vérifier que :

- seuls les nouveaux tournois affichent le badge **Nouveau** ;
- le badge disparaît automatiquement lors d'une visite ultérieure ;
- une modification d'un tournoi existant ne recrée jamais le badge.

---

## Responsive

Vérifier le comportement sur :

- smartphone ;
- tablette ;
- desktop.

L'expérience utilisateur doit rester cohérente sur l'ensemble des supports.

---

# Robustesse

Vérifier notamment que :

- aucune erreur JavaScript n'est générée ;
- aucune régression fonctionnelle n'est observée ;
- les performances restent équivalentes à la version précédente.

# Release Checklist

Avant de clôturer la sous-issue, vérifier notamment :

- les critères d'acceptation des BC-14.1 à BC-14.3 sont validés ;
- les scénarios fonctionnels sont passants ;
- la documentation est à jour ;
- aucune anomalie bloquante n'est identifiée.

---

# Hors périmètre

Cette sous-issue ne comprend pas :

- nouveaux filtres ;
- Google Calendar ;
- Usage Metrics ;
- optimisations de performance ;
- nouvelles fonctionnalités utilisateur.

Toute évolution supplémentaire sera planifiée dans une version ultérieure.

---

# Critères d'acceptation

La sous-issue est considérée terminée lorsque :

- tous les scénarios fonctionnels sont validés ;
- le comportement est identique sur desktop et mobile ;
- aucune anomalie bloquante n'est identifiée ;
- la documentation est synchronisée ;
- la Release Checklist est validée.

La version v0.14 peut alors être clôturée.

---

# Livrable attendu

À l'issue de cette sous-issue :

- BadCalendar offre une expérience utilisateur plus fluide ;
- les préférences pertinentes sont mémorisées ;
- les cartes sont plus lisibles ;
- les nouveaux tournois sont immédiatement identifiables ;
- la documentation est à jour ;
- la version v0.14 est prête à être livrée.
